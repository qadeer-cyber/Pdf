# DocuForge AI

An original, iLovePDF-inspired (not cloned) PDF SaaS blueprint focused on:

- **Traffic:** free PDF utilities and SEO tool pages
- **Revenue:** subscriptions + AI credits + API plans
- **Retention:** user workflows, dashboards, and team features

## Stack
- Next.js (App Router) + TypeScript + Tailwind + shadcn/ui
- PostgreSQL + Prisma
- Redis + BullMQ
- S3-compatible object storage
- Stripe + Resend + PostHog

## Docs
- `docs/architecture.md` – system architecture and data model
- `docs/roadmap.md` – phased 30-day execution plan
- `prompts/` – production prompts for Claude-based scaffolding
